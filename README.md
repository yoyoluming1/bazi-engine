# bazi-engine

八字排盘引擎 + [DSH](https://github.com/deepseek-ai/deepseek-harness) 工具插件。

大多数「命理 AI」是把一段玄学提示词塞给模型，**算没算、算错没有，都看不出来**。这个项目把两件事拆开：

- **算**：历法、干支、真太阳时、十神、五行力量、大运、格局 —— 由代码给出，可测试、可复现
- **说**：由模型把结果讲成人话，但它只能引用引擎给出的 `basis`，不能自己编

## 特性

| 能力 | 说明 |
|---|---|
| **真太阳时** | 经度修正 + 均时差（Spencer 近似）。差 20 分钟就换时柱，多数软件不做 |
| **四柱排盘** | 年/月/日/时，含藏干与十神标注 |
| **五行力量** | 天干 1.0、藏干 1.0/0.5/0.3、月令 ×1.5（权重是**明写的流派假设**） |
| **身强弱** | 帮扶（比劫+印）/ 总量，输出比值与档位 |
| **大运流年** | 阳男阴女顺、阴男阳女逆；起运精确到年月日；流年干支与十神 |
| **格局** | 月令取格：建禄/羊刃、藏干透干、本气格三种路径 |
| **用神** | 扶抑法：身强喜克泄耗、身弱喜生扶、中和走通关 |
| **调候** | 《穷通宝鉴》月令 × 日干表：寒暖燥湿与调候用神，与扶抑并列（两个问题正交） |
| **可解释** | 每个结论都带 `basis` 推导链 |

## 用法

### 命令行

```bash
node cli.mjs 1993-03-15 08:20 116.4
node cli.mjs 1993-03-15 08:20 116.4 --female
```

### 作为库

```js
import { chart, luck, liuNian, analyze } from 'bazi-engine'

const c = chart({ date: '1993-03-15', time: '08:20', longitude: 116.4 })
c.baZi        // '癸酉 乙卯 乙未 庚辰'
c.strength    // { grade: '偏强', ratio: 0.554, ... }

const a = analyze(c)
a.geju.name         // '建禄格'
a.yongShen.primary  // '金'
a.geju.basis        // 推导链，逐条
```

### 作为 DSH 工具

```bash
dsh plugin --profile <你的 profile> add file:/path/to/bazi-engine/dsh-plugin
```

模型会多出一个 `bazi_chart` 工具：

```
bazi_chart({ birthDate: '1993-03-15', birthTime: '08:20', longitude: 116.4, gender: 'male' })
```

## 设计纪律

1. **只实现一套判法**：月令取格 + 扶抑用神。命理流派众多，吞下所有流派等于什么都不准。
2. **结论必须可追溯**：没有 `basis` 的断言不发。用神不是「你喜水」，而是「身偏强 55.4% → 宜泄宜克 → 金有力可用」。
3. **不输出「注定/必然」**：这是推演，不是判决。
4. **默认值必须明示**：没给经度时按 116.4（北京）算，并在输出里标注这是假设。

## 测试

```bash
node --test test/
```

26 条，覆盖：

- 真太阳时的量级与边界（均时差 ±17 分钟内、跨时辰边界改变时柱）
- 已知盘的完整四柱
- 取格三条路径（建禄 / 羊刃 / 藏干透干）
- 大运顺逆（同一张盘男女不同）、起运精度
- 流年干支
- 插件契约（注册形状、输出 schema、非法入参拒绝、render 产出）
- 调候表结构完整（12 月令 × 10 日干 = 120 格）、取用优先级、未收录时的明确回退

## 局限（诚实清单）

- 只覆盖月令取格、扶抑用神与调候，**没有**神煞、合化刑冲、格局高低
- 调候表按通行摘要转录，各家版本有出入；改 `src/tiaohou.mjs` 的 TIAOHOU 即可换版本
- 身强弱的权重是假设，不同书不一样；改 `src/geju.mjs` 的常数即可换流派
- 大运只标天干十神，地支藏干十神待补
- 没有真太阳时的历史时区处理（1949 年前中国时区复杂）
